# Quaderno di parole

App per imparare le 3.000 parole italiane più importanti con traduzione in tedesco: schede, categorie e ricerca. Progressi separati per IT → DE e DE → IT con ripetizione dilazionata; funziona anche offline. I progressi restano nel browser (localStorage).

**Sfida**: test infinito sulle parole sapute (IT → DE o DE → IT) che finisce al primo errore. Risposta scritta o a voce, suoni on/off, classifica con data, ora, numero di parole e durata.

Online: https://emlxnd.github.io/quaderno/

# Quaderno di parole

App per imparare circa 2.800 parole italiane con traduzione in tedesco: schede, categorie e ricerca. I progressi restano nel browser (localStorage).

**Sfida**: test infinito sulle parole sapute (IT → DE o DE → IT) che finisce al primo errore. Risposta scritta o a voce, suoni on/off, classifica con data, ora, numero di parole e durata.

Online: https://emlxnd.github.io/quaderno/
